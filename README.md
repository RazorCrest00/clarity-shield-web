# Clarity Shield

[Open Clarity Shield](https://razorcrest00.github.io/clarity-shield-web/)

This repository contains the published web build. Development source remains in a separate private repository.

Messages, screenshot OCR, and uploaded-recording transcription are processed in the browser. Live speech recognition depends on the browser. Session content is held in the open tab.

Model attribution and licenses: [models/README.md](models/README.md).
Demo provenance and third-party recording rights: [demos/README.md](demos/README.md).

Bundled package license notices are retained under `licenses/`.
